# schulevault

**schulevault** is an Obsidian vault: a well-organized collection of school notes and resources, built for use with the [Obsidian](https://obsidian.md/) knowledge management app. This repository is intended solely to view my personal school notes or to serve as inspiration for your own note-taking workflows.

## What is schulevault?

schulevault provides a glimpse into my actual school note-taking system. It showcases how I organize class notes, assignments, and diagrams, including folder structure, templates, and plugin usage. The content is *not* meant for direct reuse or modification; instead, it’s here so others can browse, learn from, or adapt some best practices for their own vaults.

## What is Obsidian?

[Obsidian](https://obsidian.md/) is a powerful, privacy-focused note-taking tool that works with local Markdown files. It supports advanced features like backlinks, graph view, and a robust plugin ecosystem, making it ideal for building a personal knowledge base or study vault.

## How to View schulevault

1. **Clone or Download the Repository**
   - Clone via Git:
     ```git clone https://github.com/PatrickMagAnime/schulevault.git```
   - Or download as ZIP from the [GitHub page](https://github.com/PatrickMagAnime/schulevault).

2. **Install Obsidian**
   - Get it free from [obsidian.md/download](https://obsidian.md/download).

3. **Open in Obsidian**
   - Start Obsidian.
   - Select "Open folder as vault" and choose the downloaded `schulevault` folder.

4. **Browse Notes and Structure**
   - Explore the various folders for subjects, assignments, and resources.
   - View example notes, diagrams, summaries, and plugin configurations.

## Plugins Used in This Vault

schulevault leverages a curated set of plugins to enhance note-taking, formatting, automation, and study workflows. If you want to replicate the environment or understand how certain features work, these are the plugins you’ll find in this vault:

- **better-word-count**  
  Provides accurate word/character counting for notes.

- **calctex**  
  Enables LaTeX-based calculations and math rendering.

- **custom-font-loader**  
  Allows custom fonts in your vault for improved readability.

- **dataview**  
  Query, analyze, and visualize your notes with powerful queries.

- **drawio-obsidian**  
  Integrates diagrams from draw.io directly into notes.

- **github-copilot**  
  AI-powered suggestions (if enabled).

- **highlightr-plugin**  
  Syntax highlighting for code blocks and text.

- **image2latex**  
  Converts images to LaTeX for mathematical notes.

- **ink**  
  Handwritten note support and drawing tools.

- **mathpad**  
  Advanced mathematics support.

- **obsidian-enhancing-export**  
  Enhanced export options for notes.

- **obsidian-excalidraw-plugin**  
  Interactive whiteboard-style drawings and diagrams.

- **obsidian-git**  
  Git integration for version control and backup.

- **obsidian-imgur-plugin**  
  Direct image uploads to Imgur.

- **obsidian-importer**  
  Import notes from other sources.

- **obsidian-latex-suite**  
  Comprehensive LaTeX support.

- **obsidian-math-plus**  
  Extra math and equation features.

- **obsidian-outliner**  
  Better outlining and bullet management.

- **obsidian-style-settings**  
  Custom style settings for themes and plugins.

- **obsidian-textgenerator-plugin**  
  AI text generation for note drafting.

- **omnisearch**  
  Enhanced search capabilities.

- **oz-image-plugin**  
  Image handling utilities.

- **remotely-save**  
  Remote sync for notes.

- **table-editor-obsidian**  
  Table editing support.

- **templater-obsidian**  
  Advanced templating and automation.

- **text-extractor**  
  Extract text from images and PDFs.

- **unicode-search**  
  Quickly search and insert Unicode symbols.
