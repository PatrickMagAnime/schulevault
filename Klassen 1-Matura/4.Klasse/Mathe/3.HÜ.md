**b)**
$y' + 2y = 5\cos t,\; y(0)=0$

$y_h = C e^{-2t}$

$y_p = A\cos t + B\sin t$

$y_p' = -A\sin t + B\cos t$

$(-A\sin t + B\cos t) + 2(A\cos t + B\sin t) = 5\cos t$

$\text{Koeffizientenvergleich:}$
$\cos t:\; B + 2A = 5$
$\sin t:\; -A + 2B = 0$

$-A + 2B = 0 \Rightarrow A = 2B$

$B + 2(2B) = 5 \Rightarrow 5B = 5 \Rightarrow B = 1 \Rightarrow A = 2$

$y_p = 2\cos t + \sin t$

$y = C e^{-2t} + 2\cos t + \sin t$

$y(0)=0:\; 0 = C + 2 \Rightarrow C = -2$

$\boxed{y(t) = 2\cos t + \sin t - 2 e^{-2t}}$

$\text{Kontrolle (Integrierender Faktor): } \mu(t)=e^{\int 2 dt}=e^{2t}$

$\frac{d}{dt}(e^{2t} y) = 5 e^{2t}\cos t$

$\int e^{2t}\cos t\, dt = \frac{e^{2t}(2\cos t + \sin t)}{5}$

$e^{2t} y = e^{2t}(2\cos t + \sin t) + C$

$y = 2\cos t + \sin t + C e^{-2t},\; C=-2$

$y = 2\cos t + \sin t - 2 e^{-2t}$

**a)**
$\ \text{Gegebene DGL: } y'' + y' - 2y = 0$
$\ \text{Lineare homogene DGL mit konstanten Koeffizienten. Ansatz } y = e^{rx} \text{ (}\neq 0\text{).}$
$\ \text{Ableitungen des Ansatzes: } y' = r e^{rx},\; y'' = r^{2} e^{rx}$
$\ \text{Einsetzen in die DGL: } r^{2} e^{rx} + r e^{rx} - 2 e^{rx} = 0$
$\ e^{rx} \text{ ist nie } 0 \Rightarrow r^{2} + r - 2 = 0 \text{ (charakteristische Gleichung)}$
$\ \text{Faktorisieren: } r^{2} + r - 2 = (r+2)(r-1)=0$
$\ \text{Wurzeln: } r_{1}=1,\; r_{2}=-2$
$\ \text{Zwei verschiedene reelle Wurzeln } \Rightarrow \text{Fundamentalsystem } \{e^{x}, e^{-2x}\}$
$\ \text{Linearkombination liefert allgemeine Lösung: } y(x)=C_{1} e^{x} + C_{2} e^{-2x}$
$\ \text{Optionaler Check: } y' = C_{1} e^{x} -2 C_{2} e^{-2x},\; y'' = C_{1} e^{x} +4 C_{2} e^{-2x}$
$\ y'' + y' -2y = (C_{1} e^{x} +4 C_{2} e^{-2x}) + (C_{1} e^{x} -2 C_{2} e^{-2x}) -2(C_{1} e^{x} + C_{2} e^{-2x}) = 0$
$\ \boxed{y(x)=C_{1} e^{x} + C_{2} e^{-2x}}$

**f)**
$\ \text{Gegebene DGL: } y'' + 6y' + 9y = 0$
$\ \text{Ansatz } y=e^{rx}$
$\ y' = r e^{rx},\; y'' = r^{2} e^{rx}$
$\ \text{Einsetzen: } r^{2} e^{rx} + 6 r e^{rx} + 9 e^{rx} = 0$
$\ e^{rx} \neq 0 \Rightarrow r^{2} + 6r + 9 = 0$
$\ \text{Faktorisieren: } r^{2} + 6r + 9 = (r+3)^{2}=0$
$\ \text{Doppelte (zweifache) Wurzel: } r=-3$
$\ \text{Erste Lösung: } y_{1}=e^{-3x}$
$\ \text{Zur zweiten Lösung bei doppelter Wurzel: } y_{2}=x e^{-3x} \text{ (Regel: } x^{k} e^{rx} \text{ für k=0,1 bei Einfach-/Doppelwurzel)}$
$\ \text{Begründung durch Reduktion der Ordnung: setze } y = v(x) e^{-3x}$
$\ y' = v' e^{-3x} -3 v e^{-3x},\; y'' = v'' e^{-3x} -6 v' e^{-3x} +9 v e^{-3x}$
$\ \text{Einsetzen in DGL: } (v'' e^{-3x} -6 v' e^{-3x} +9 v e^{-3x}) + 6(v' e^{-3x} -3 v e^{-3x}) + 9 v e^{-3x} = 0$
$\ \text{Kürzen: } v'' e^{-3x} -6 v' e^{-3x} +9 v e^{-3x} +6 v' e^{-3x} -18 v e^{-3x} +9 v e^{-3x} = v'' e^{-3x} = 0$
$\ v'' = 0 \Rightarrow v' = A \Rightarrow v = A x + B$
$\ y = (A x + B) e^{-3x} = B e^{-3x} + A x e^{-3x}$
$\ \text{Umbenennen der Konstanten } C_{1}=B,\; C_{2}=A \Rightarrow y = (C_{1} + C_{2} x) e^{-3x}$
$\ \text{Allgemeine Lösung: } y(x) = (C_{1} + C_{2} x) e^{-3x}$
$\ \text{Optionaler Check: } y' = (C_{2} -3(C_{1} + C_{2} x)) e^{-3x}$
$\ y'' = (-3C_{2} +9(C_{1} + C_{2} x) -3 C_{2}) e^{-3x} = (9(C_{1} + C_{2} x) -6 C_{2}) e^{-3x}$
$\ y'' + 6y' + 9y = [9(C_{1}+C_{2} x) -6C_{2}] e^{-3x} + 6[C_{2} -3(C_{1}+C_{2} x)] e^{-3x} + 9(C_{1}+C_{2} x) e^{-3x} = 0$
$\ \boxed{y(x) = (C_{1} + C_{2} x) e^{-3x}}$
