inhomogen:
wir wissen durch das Ergebnis das es polynom Funktion ist ($y_p = a x² + b x + c$)
$y_p' = 2a x + b$ ist unser normalwert also mit einsetzen dann:
$(a x² + b x + c)'-4(a x² + b x + c)$ =
$(2a x + b)-4(a x² + b x + c)$ =
$2ax+b-4ax^{2}-4bx-4c$ =
$-4ax^{2}+2ax+b-4bx-4c$=
a = −8
b = −4
c = −1
$y_p = −8x² − 4x − 1$
$y(x) = y_h + y_p = C e^{4x} − 8x² − 4x − 1$
und jz einsetzen:

(2ax + b) - 4(ax^{2} + bx + c) = 32x^{2}$
-4a = 32 \Rightarrow a = -8,\qquad 2a - 4b = 0 \Rightarrow -16 - 4b = 0 \Rightarrow b = -4,\qquad b - 4c = 0 \Rightarrow -4 - 4c = 0 \Rightarrow c = -1$
y_p = -8x^{2} - 4x - 1$
y = C e^{4x} - 8x^{2} - 4x - 1,\quad y(0)=2 \Rightarrow C - 1 = 2 \Rightarrow C=3$

\text{Ansatz Partikulär:}\; y_p = A e^{x},\quad y_p' = A e^{x}$
y_p' + y_p = 2A e^{x} = 2 e^{x} \Rightarrow A = 1 \Rightarrow y_p = e^{x}$
$y = C e^{-x} + e^{x},\quad y(0)=6 \Rightarrow C + 1 = 6 \Rightarrow C=5$
$\boxed{y(x) = 5 e^{-x} + e^{x}}$
