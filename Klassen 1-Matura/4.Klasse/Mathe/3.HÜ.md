$y' + 2y = 5\cos t,\; y(0)=0$
$y_h = C e^{-2t}$
$y_p = A\cos t + B\sin t$
$y_p' = -A\sin t + B\cos t$
$(-A\sin t + B\cos t) + 2(A\cos t + B\sin t) = 5\cos t$

$\text{Koeffizientenvergleich:}$
$\cos t:\; B + 2A = 5$
$\sin t:\; -A + 2B = 0$
$-A + 2B = 0 \Rightarrow A = 2B$
$B + 2(2B) = 5 \Rightarrow 5B = 5 \Rightarrow B = 1 \Rightarrow A = 2$
$y_p = 2\cos t + \sin t$
$y = C e^{-2t} + 2\cos t + \sin t$
$y(0)=0:\; 0 = C + 2 \Rightarrow C = -2$
$\boxed{y(t) = 2\cos t + \sin t - 2 e^{-2t}}$

$\text{Kontrolle (Integrierender Faktor): } \mu(t)=e^{\int 2 dt}=e^{2t}$
$\frac{d}{dt}(e^{2t} y) = 5 e^{2t}\cos t$
$\int e^{2t}\cos t\, dt = \frac{e^{2t}(2\cos t + \sin t)}{5}$
$e^{2t} y = e^{2t}(2\cos t + \sin t) + C$
$y = 2\cos t + \sin t + C e^{-2t},\; C=-2$
$y = 2\cos t + \sin t - 2 e^{-2t}$

$\ \text{Wurzeln: } r_{1}=1,\; r_{2}=-2$

$\ \text{Gegebene DGL: } y'' + 6y' + 9y = 0$
$\ \text{Ansatz } y=e^{rx}$
$\ y' = r e^{rx},\; y'' = r^{2} e^{rx}$
$\ \text{Einsetzen: } r^{2} e^{rx} + 6 r e^{rx} + 9 e^{rx} = 0$

$\ \text{Erste Lösung: } y_{1}=e^{-3x}$
$\ \text{Zur zweiten Lösung bei doppelter Wurzel: } y_{2}=x e^{-3x} \text{ (Regel: } x^{k} e^{rx} \text{ für k=0,1 bei Einfach-/Doppelwurzel)}$

$\ y' = v' e^{-3x} -3 v e^{-3x},\; y'' = v'' e^{-3x} -6 v' e^{-3x} +9 v e^{-3x}$
$\ \text{Einsetzen in DGL: } (v'' e^{-3x} -6 v' e^{-3x} +9 v e^{-3x}) + 6(v' e^{-3x} -3 v e^{-3x}) + 9 v e^{-3x} = 0$

**a)**
$y'' + 4y' + 3y = 6$
Art erkennen: lineare inhomogene DGL 2. Ordnung mit konstanten Koeffizienten.
Homogener Teil bilden: $y'' + 4y' + 3y = 0$.
Ansatz für homogene Lösung: $y_h = e^{rx}$ (weil Exponentialfunktionen bei konstanten Koeffizienten passen).
Ableitungen einsetzen: $y_h' = r e^{rx},\; y_h'' = r^{2} e^{rx}$.
Einsetzen in homogene Gleichung: $r^{2} e^{rx} + 4r e^{rx} + 3 e^{rx} = 0$.
Faktor $e^{rx} \neq 0$ heraus: charakteristische Gleichung $r^{2} + 4r + 3 = 0$.
Faktorisieren: $(r+1)(r+3)=0$.
Wurzeln bestimmen: $r_1 = -1,\; r_2 = -3$.
Fundamentalsystem (zwei verschiedene reelle Wurzeln): $e^{-x}, e^{-3x}$.
Homogene Lösung: $y_h = C_1 e^{-x} + C_2 e^{-3x}$.
Inhomogene rechte Seite ist Konstante $6$. Für eine konstante rechte Seite wähle einen konstanten Ansatz $y_p = A$ (Annihilator-Methode: Operator $(D)$ auf Konstante 0, vorhandene Exponenten $-1,-3$ ≠ 0 → kein Resonanzproblem).
Ableitungen des Ansatzes: $y_p' = 0,\; y_p'' = 0$.
Einsetzen in volle DGL: $0 + 0 + 3A = 6$.
Lösen: $A = 2$.
Partikuläre Lösung: $y_p = 2$.
Gesamtlösung: $y = y_h + y_p = C_1 e^{-x} + C_2 e^{-3x} + 2$.
Optionaler Check: $y' = -C_1 e^{-x} -3 C_2 e^{-3x}$, $y'' = C_1 e^{-x} +9 C_2 e^{-3x}$.
Einsetzen: $y'' + 4y' + 3y = (C_1 e^{-x} +9 C_2 e^{-3x}) + 4(-C_1 e^{-x} -3 C_2 e^{-3x}) + 3(C_1 e^{-x} + C_2 e^{-3x} + 2) = 6$.
Fertig: $y(x) = C_1 e^{-x} + C_2 e^{-3x} + 2$.

**b)**
$y'' + 4y' + 3y = 3x + 1$
Homogene Gleichung identisch wie bei a): $y'' + 4y' + 3y = 0$.
Charakteristische Gleichung: $r^{2} + 4r + 3 = 0$.
Faktorisieren: $(r+1)(r+3)=0$.
Wurzeln: $r_1=-1,\; r_2=-3$.
Homogene Lösung: $y_h = C_1 e^{-x} + C_2 e^{-3x}$.
Rechte Seite ist Polynom Grad 1: $3x+1$. Standard-Ansatz für Polynom Grad 1: $y_p = Ax + B$.
Resonanzprüfung: Exponentiellen Teile haben Raten $-1,-3$; keine Überschneidung mit Polynom-Anteil (Polynom entspricht Wurzel $r=0$ im Annihilator $D^{2}$). $r=0$ ist keine Wurzel der charakteristischen Gleichung → einfacher Ansatz reicht.
Ableitungen: $y_p' = A,\; y_p'' = 0$.
Einsetzen: $0 + 4A + 3(Ax + B) = 3x + 1$.
Sortieren nach Potenzen: $(3A)x + (4A + 3B) = 3x + 1$.
Koeffizientenvergleich:
$x$-Term: $3A = 3 \Rightarrow A = 1$.
Konstante: $4A + 3B = 1 \Rightarrow 4 + 3B = 1 \Rightarrow 3B = -3 \Rightarrow B = -1$.
Partikuläre Lösung: $y_p = x - 1$.
Gesamtlösung: $y = C_1 e^{-x} + C_2 e^{-3x} + x - 1$.
Optionaler Check: $y' = -C_1 e^{-x} -3 C_2 e^{-3x} + 1$, $y'' = C_1 e^{-x} + 9 C_2 e^{-3x}$.
Einsetzen: $y'' + 4y' + 3y = (C_1 e^{-x} + 9 C_2 e^{-3x}) + 4(-C_1 e^{-x} -3 C_2 e^{-3x} +1) + 3(C_1 e^{-x} + C_2 e^{-3x} + x -1)$.
Kürzen der Parameterterme ergibt $3x + 1$; somit korrekt.
Fertig: $y(x) = C_1 e^{-x} + C_2 e^{-3x} + x - 1$.

**c)**
$y'' + 4y' + 8y = 16x$
Homogene Gleichung: $y'' + 4y' + 8y = 0$.
Charakteristische Gleichung: $r^{2} + 4r + 8 = 0$.
Diskriminante: $\Delta = 4^{2} - 4\cdot 1 \cdot 8 = 16 - 32 = -16$ (negativ → komplexe Wurzeln).
Wurzeln: $r = \frac{-4 \pm \sqrt{-16}}{2} = \frac{-4 \pm 4i}{2} = -2 \pm 2i$.
Darstellung reeller homogener Lösung aus $r = \alpha \pm \beta i$: $y_h = e^{\alpha x}(C_1 \cos \beta x + C_2 \sin \beta x)$ mit $\alpha=-2,\ \beta=2$.
Also: $y_h = e^{-2x}(C_1 \cos 2x + C_2 \sin 2x)$.
Rechte Seite ist Polynom Grad 1: $16x$ → Ansatz $y_p = Ax + B$.
Resonanzprüfung: Polynom korrespondiert zu Wurzel $r=0$ (Operator $D$). $0$ ist keine Wurzel der charakteristischen Gleichung ($-2 \pm 2i$) → Ansatz ok.
Ableitungen: $y_p' = A,\; y_p'' = 0$.
Einsetzen: $0 + 4A + 8(Ax + B) = 16x$.
Sammeln: $(8A)x + (4A + 8B) = 16x + 0$.
Koeffizientenvergleich:$x$-Term: $8A = 16 \Rightarrow A = 2$.Konstante: $4A + 8B = 0 \Rightarrow 8 + 8B = 0 \Rightarrow B = -1$.
Partikuläre Lösung: $y_p = 2x - 1$.
Gesamtlösung: $y = e^{-2x}(C_1 \cos 2x + C_2 \sin 2x) + 2x - 1$.
Optionaler Check:$y_p' = 2$, $y_p''=0$.
Homogener Teil erfüllt Null (Definitionsgemäß).
Für $y_p$: $0 + 4\cdot 2 + 8(2x -1) = 8 + 16x -8 = 16x$ passt.
Fertig: $y(x) = e^{-2x}(C_1 \cos 2x + C_2 \sin 2x) + 2x - 1$.
